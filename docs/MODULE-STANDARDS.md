# BIOL 1113 — Module Standards

How to build, structure, and name every module in this course.
Read this before creating or editing any week folder.

---

## File Structure

Each `weekNN/` folder contains one HTML source file:

| File | Canvas page | Purpose |
|------|-------------|---------|
| `week.html` | Week N | Objectives, learning materials (videos + readings in sequence), assignments |

No other HTML files belong in week folders. Slides live in `slides/weekNN/`.

> Legacy stub files (`overview.html`, `materials.html`, `assignments.html`) may exist in week folders
> but are ignored by the build pipeline.

---

## Naming Conventions

- Folders: `week01` through `week15` (zero-padded)
- File: exactly `week.html`
- Canvas page slug: `biol1113-week01-week` (auto-generated by `upload_to_canvas.py`)

## Content Rules

### Readings
- Always link to specific OpenStax Biology 2e sections, never the chapter root
- Never assign full chapters
- Include a one-sentence note on what to look for in each reading
- Readings use the `.reading-card` component

### Videos
- Each instructor video gets its own `.video-card`
- Title = descriptive topic name, not "Video 1" or "Lecture 3"
- Runtime listed in video-meta
- Every video card ends with a `.notes-label`/`.notes-text` pair pointing students to that
  week's Learning Notes assignment — see "Learning Notes marker" below. (Retired Aug 14,
  2026: the old per-video "As you watch, focus on:" pre-watch priming questions
  (`.focus-label`/`.focus-questions`) — structured Learning Notes now cover that job.)

### Objectives
- 4–6 measurable objectives per week
- Use action verbs: explain, describe, compare, predict, distinguish, apply, trace, analyze
- Avoid "understand" and "know" — they are not measurable
- Objectives go in the `.objectives-box` at the top of `week.html`

### Learning Materials Order
- Place `.video-card` and `.reading-card` blocks in the order students should work through them
- Interleave videos and readings as the topic requires — do not group all videos or all readings together
- Use `.material-label` ("View and engage with:" / "Read:") before each group of items

### Week 1 Learning Notes Reminder
- Week 1 only, every target (sandbox/live/hybrid): a `.notice-box` right after the `.seq-note`
  and before the first video, reading `<strong>Reminder!</strong> These must be uploaded to
  your Learning Notes assignment at the end of the week.` This is the students' first
  exposure to the per-video Learning Notes markers, so it gets called out once up front —
  weeks 2-15 rely on the markers alone. Added Aug 14, 2026 to `week01/week.html`; carries into
  `hybrid/week01/week.html` automatically via `create_hybrid_week_pages.py` since it sits
  outside the video-1 block that script replaces.

### Assignments
- **Lean by design: assignment name linked to the Canvas assignment/quiz, nothing else.**
  Points, descriptions, and due dates live on the Canvas assignment itself, not on the week
  page — that's what keeps a grading-scheme or schedule change from requiring an edit across
  15 week pages, and keeps this template reusable for a different course or point scheme.
- Use the `.assignment-links` component (a plain `<ul>` of `<li><a>` items) in the Assignments
  section of `week.html`
- Once an item's Canvas assignment/quiz exists, link it directly (real URL). Until then, use
  `<li class="unlinked">Name</li>` — see `templates/week.html` for the pattern — never a dead link
- Learning Notes is present every week; Blog Post appears weeks 2–15; Test reminders appear
  automatically on test weeks (`scripts/create_week_pages.py` generates these)

### Due Dates
- All work due Sunday 11:59 PM — stated once in the page header (`.page-subtitle`)
- The per-assignment due date lives on the Canvas assignment, not duplicated on the week page
- Never say "by the end of the week" — state the specific date

### Supplemental Resources
- Maximum 1–2 per week
- External curated content only (not instructor-created)
- Marked clearly as optional
- Keep the section short — do not let it compete with required content

## CSS Components

All styles come from `course-styles.css`. Never write inline styles manually or add `<style>` blocks.

| Component | Class | Use for |
|-----------|-------|---------|
| Page header | `.page-header` | Top of page |
| Week label | `.week-label` | Inside page header |
| Objectives box | `.objectives-box` | Learning objectives |
| Material label | `.material-label` | "View and engage with:" / "Read:" labels |
| Sequence note | `.seq-note` | "Complete in order" note after Learning Materials h2 |
| Video card | `.video-card` | Each video lesson |
| Learning Notes marker | `.notes-label` / `.notes-text` | Inside every `.video-card`, in place of the retired focus questions — flags that this video's notes go in the week's Learning Notes assignment. Wording every time: `Learning Notes <--- Download here` + `Take notes as you watch — upload them with this week's Learning Notes assignment.` Where a guided-notes handout exists for that video, the label is a link: `<a href="{{NOTES_URL:<key>}}" target="_blank">Learning Notes <--- Download here</a>` — same `{{NOTES_URL:<key>}}`/`canvas_targets.py`-per-target pattern as `{{SLIDES_URL:<key>}}` (see `scripts/upload_learning_notes_to_canvas.py`). A video with no guided-notes handout yet keeps the plain (unlinked) label. |
| Reading card | `.reading-card` | Each reading assignment |
| Assignment links | `.assignment-links` | Lean list of name → Canvas link, in the Assignments section |
| Notice box | `.notice-box` | Optional/supplemental callouts, and the Week 1 Learning Notes reminder (see below) |
| Lecture notice | `.lecture-notice` | **Hybrid course only.** Replaces the first `.video-card` each week — that content is covered live at Monday lecture instead of watched online. See `hybrid/weekNN/week.html`. |

## Hybrid Course Variant

The hybrid course (`hybrid/` folder, target `hybrid` in `canvas_targets.py`) shares this file's conventions with three differences:

- Its first weekly video slot uses `.lecture-notice` instead of `.video-card` — no focus questions underneath, per Jodie's decision (Aug 13, 2026).
- Its Assignments list uses `{{SMALL_GROUP_URL}}` ("Small Group Participation") in place of `{{BLOG_POST_URL}}` / `{{BLOG_COMMENT_URL}}` — there is no Blog Post or Blog Comment Declaration in the hybrid course.
- A "Small Group" section appears right after Objectives, before Learning Materials, every week: a one-line paragraph pointing students to their assigned small group meeting and the declaration they owe afterward, with "your assigned small group meeting" linking to the course's "Small Groups" wiki page (`/courses/{{COURSE_ID}}/pages/small-groups`). Added Aug 14, 2026 at Jodie's request, once that Canvas page existed.

Don't hand-edit `hybrid/weekNN/week.html` directly except for hybrid-only differences (the lecture notice, the assignments list, the Small Group section). For everything else (videos 2+, readings, objectives), edit the root `weekNN/week.html` and re-run `python3 scripts/create_hybrid_week_pages.py` — it regenerates the hybrid page from the current root content, so the two never drift apart.

## Build and Upload Workflow

1. Edit source HTML files in `weekNN/` (or `hybrid/weekNN/` for the hybrid course) — these preview correctly in a browser
2. Edit `course-styles.css` for any style changes
3. Run `bash build/build.sh <target>` (`sandbox`, `live`, or `hybrid`) to generate Canvas-ready HTML in `build/biol1113-<target>/`
4. Run `python3 scripts/upload_to_canvas.py <target>` to push to Canvas (uploads as drafts)
5. Review and publish in Canvas

Never edit files in `build/biol1113-<target>/` — they are overwritten on every build.

|------|------|--------|

| CSS | ✅ course-styles.css | inlined at build time |

| Videos | ❌ too large | ✅ Kaltura/Canvas |
| Learning Notes assignments | ❌ created via `scripts/create_learning_notes_group.py` | ✅ Canvas assignments |
| Test questions | ❌ gitignored | ✅ Canvas quizzes |
| Student grades/data | ❌ never | ✅ Canvas gradebook only |
| Canvas API token | ❌ .env only | N/A |
